# Sticker setup

Wild Hackemon live on NFC stickers. Each sticker holds one NDEF Text record. The badge's
reader handles any ISO 14443A tag, and NTAG213 or NTAG215 stickers are the cheapest option.

## Writing a sticker

1. Install **NFC Tools** on an Android phone or iPhone.
2. Choose **Write**, then **Add a record**, then **Text**.
3. Type the code, for example `HKM07`.
4. Tap **Write** and hold the phone on the sticker until it confirms.
5. Check it with the badge's Tag Scanner app before hiding it.

## Codes

| Code | Creature | Type | Notes |
| --- | --- | --- | --- |
| `HKM01` | Soldrat | HW | Starter option |
| `HKM02` | Neuron | AI | Starter option |
| `HKM03` | Crawly | WEB | Starter option |
| `HKM04` | Pixie | DSGN | |
| `HKM05` | Lockjaw | SEC | Tanky |
| `HKM06` | Kernel | SYS | |
| `HKM07` | Voltra | HW | Glass cannon |
| `HKM08` | Gradient | AI | |
| `HKM09` | Cachemander | SYS | Rare, hide it well |
| `HKM10` | Rootkat | SEC | Rare, hide it well |

Append `L` and a number for a stronger wild, for example `HKM09L5` for a level 5
Cachemander. Level raises HP by 3 and attack by 1 per level. A caught creature keeps the
level it was caught at, so higher-level stickers are worth the walk.

## Placement ideas

- Put the three starters near the entrance so everyone can catch a second creature fast.
- Put one sticker at each sponsor booth.
- Put the rare ones far away or somewhere that needs a hint.
- One sticker per code is enough. Any number of hackers can scan the same sticker.
